# Dear Editors

Небольшое закрытое корпоративное медиа с характером.

Каждая хорошая редакция знает две вещи:

> До дорогой редакции дошел слух…

и

> Будем наблюдать.

Редакционный голос и правила заметки зафиксированы в [EDITORIAL_STYLE.md](EDITORIAL_STYLE.md).

## Первый релиз

Dear Editors намеренно маленький: закрытая редакционная лента, отдельная страница публикации, собственный редакционный стол, почта редакции и вход по одноразовым приглашениям. Публикации имеют статусы `draft` / `published`; читателям доступны только опубликованные материалы.

Редакции также доступен удаленный MCP для подготовки материалов через Perplexity. Он умеет читать контекст и работать с черновиками, но не публикует материалы самостоятельно.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate  # Windows Git Bash: source .venv/Scripts/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
python manage.py runserver
```

После запуска:

- `/login/` — вход во внутреннее издание;
- `/` — редакционная лента после входа;
- `/editor/` — редакционный стол для `is_staff`;
- `/editor/invites/` — приглашения читателей;
- `/admin/` — запасной Django Admin;
- `/health/` — техническая проверка приложения и базы;
- `/mcp/` — редакционный MCP, если настроен отдельный API-ключ.

## Проверка

```bash
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test
```

## Принципы

- сначала законченный вертикальный срез, потом новые фичи;
- обычный Django без SPA и лишней инфраструктуры;
- выразительная типографика и редакционный характер;
- в редакционных и интерфейсных текстах используем только `е`;
- агент может готовить материал, но публикация остается редакционным решением человека;
- не превращать маленькое корпоративное медиа в инфраструктуру Reuters раньше времени.
