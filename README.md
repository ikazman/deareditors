# DearEditors

Небольшое корпоративное медиа с характером.

Каждая хорошая редакция знает две вещи:

> До дорогой редакции дошёл слух…

и

> Будем наблюдать.

## Идея

DearEditors — лёгкое внутреннее медиа для заметок, новостей и редакционных наблюдений. Первый релиз намеренно маленький: публичная лента, отдельная страница публикации и удобная редактура через Django Admin.

## Принципы

- сначала законченный вертикальный срез, потом новые фичи;
- обычный Django без SPA и лишней инфраструктуры;
- выразительная типографика и редакционный характер;
- публикации имеют статусы `draft` / `published`;
- публичная часть показывает только опубликованные материалы.
